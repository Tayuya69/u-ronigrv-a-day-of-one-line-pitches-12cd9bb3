Entry for the [A Day of One-Line Pitches](https://make.fun/competitions/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3) bounty on [make.fun](https://make.fun).

`main.ts` (Node 22) writes one sentence to `/output/entry.txt` — a single
sentence meant to convince a friend who has never coded to let an AI agent
build their first app idea on make.fun. Outside the grader, set
`MAKEFUN_OUTPUT_DIR` to stand in for `/output`. The program is fully
deterministic: the sentence is a fixed string, with no network, clock, or
randomness, so repeated runs write byte-identical output.
